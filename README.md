# 🥗 Projeto Nutricionista Ana Beatriz

> Site institucional profissional desenvolvido em **HTML5** e **SASS**, com layout responsivo e animações modernas.  
> Criado como exercício de conversão de CSS para SASS, aplicando boas práticas de modularização e reutilização de código.

---

## 💡 Sobre o Projeto
Este site apresenta os **planos nutricionais da Nutricionista Ana Beatriz**, com design limpo, profissional e totalmente adaptável para **celulares, tablets e desktops**.

Foram aplicados princípios de responsividade, animações sutis e uma hierarquia visual agradável, garantindo uma experiência fluida para o usuário.

---

## 🧠 Objetivos do Exercício
- Converter todo o CSS do projeto original em **SASS**
- Utilizar **variáveis**, **mixins** e **módulos**
- Organizar o código em uma estrutura escalável e limpa
- Criar uma branch exclusiva (`exercicio_sass`)
- Enviar o projeto completo para o GitHub

---

## ⚙️ Tecnologias Utilizadas
- 🧩 HTML5  
- 🎨 SASS (Dart Sass)  
- 💻 VS Code  
- 🧱 Git & GitHub
